# Forge Settlement Scenery Kit

This is the project-authored Forge Settlement scenery kit for Sound Seekers,
produced on 17 July 2026 with OpenAI image generation and manually isolated onto
fixed transparent gameplay canvases with nearest-neighbour sampling.

The kit contains a Gearworks gate, ore hopper, plate foundry, night train, Word
Forge, workshop market, steam pipes, tool rack, rail signal, ore cart, authored
sorting conveyor, and collectible ember rivet. Each landmark has a distinct
silhouette and material story so the five Forge stops no longer read as one
repeated industrial backdrop.

These project-authored files are not part of the upstream Ninja Adventure CC0
pack documented at `public/game-assets/quest-pixel/SOURCE.md`.
