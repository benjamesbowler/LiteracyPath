# Forge Settlement Interaction Kit

This is the project-authored Forge Settlement interaction kit for Sound Seekers,
produced on 17 July 2026 with OpenAI image generation and manually isolated onto
fixed transparent gameplay canvases with nearest-neighbour sampling.

The kit contains a machine gear, ore tray, hot forge rune, rail trolley, word
plate, and assembly socket. These props give each phonics verb a physical object
with a readable silhouette instead of a generic circle, box, or floating label.

These project-authored files are not part of the upstream Ninja Adventure CC0
pack documented at `public/game-assets/quest-pixel/SOURCE.md`.
