# Fossil Canyon Interaction Kit

This project-authored Fossil Canyon interaction kit was produced for Sound
Seekers on 17 July 2026 with OpenAI image generation, then manually curated into
fixed transparent game canvases.

The six physical task objects share the chapter cast and scenery palette:

- `fossil-rune.png` (`80x80`)
- `track-marker.png` (`80x80`)
- `fitted-bone.png` (`80x80`)
- `rescue-flag.png` (`80x80`)
- `fossil-beacon.png` (`88x88`)
- `brush-station.png` (`96x96`)

The generated source grid was chroma-keyed, inspected at final scale,
point-sampled, and aligned to transparent canvases. Letter labels are added by
the renderer as body-mounted badges so the same object art can carry every
curriculum target without detached placards.
