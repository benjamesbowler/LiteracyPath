# Recording Script — one take, 61 items (print this page)

**Yes: record it as ONE mp3.** I will split, trim, compress and file every clip
automatically — the pauses are how I find the cuts, so they matter.

## How to record
1. Quiet room, phone or laptop mic is fine (hold it ~20cm away, same position throughout).
2. Speak warmly and clearly, like reading to a class of 5-year-olds.
3. Say each item ONCE, then stay SILENT for a slow "one-banana, two-banana"
   (~2 seconds) before the next item. The silence is essential.
4. If you fluff one, just pause, then say the SAME item again — I keep the last
   good take of any repeated item. Don't restart the recording.
5. Save/export as mp3 (or m4a/wav — anything), drop it in a folder on the
   Desktop, and tell Claude it's there.

## Part 1 — Letter SOUNDS (say the sound, NEVER the letter's name)
Stop sounds = one crisp sound, no "uh" after it. Stretchy sounds = hold ~half a second.
