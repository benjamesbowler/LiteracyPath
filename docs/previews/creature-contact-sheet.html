Sound Seekers — the creature

Every creature below is drawn by the same code the app will run (src/utils/creatureLayout.js), from 6 body shapes, 12 dyes and ~55 vector parts. Nothing here is a mock-up.

The one question this page exists to answer: does a layered-vector creature look good enough for a child to love and want to dress up?
If yes, I build the Den, the map and stop 1 on top of it.
If no, we fall back to a pal base with layered accessories — one slice lost, not the project.
