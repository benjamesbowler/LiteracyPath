# Kimi Audio Request — Pronunciation Fixes + Slower Pace

Replacements for recordings that teach the wrong sound or move too fast
for 4-7 year olds. Same warm female narrator as before, with these
NON-NEGOTIABLE pronunciation rules:

> **Flat short A everywhere.** "ant" must rhyme with "pant" (the /ae/
> sound, as in "cat") - NEVER "aunt". "ax" like "tax" - never "arks".
> Use the short, flat Northern-English style A for every a-word in this
> file. No long "ah" sounds in any short-vowel word.
>
> **Pace.** Single words: one clear, unhurried word. Sentences: read
> SLOWLY for a learning reader - roughly 30 percent slower than natural
> speech, with a tiny gap between every word, but still warm and
> natural, never robotic.
