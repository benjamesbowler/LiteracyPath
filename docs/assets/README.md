# Asset QA Notes

Use `docs/assets/kimi_master_replacement_queue.md` as the active source of truth for Kimi replacement work.

Use `docs/assets/story_quest_asset_audit.md` as the current Story Quest media audit. It lists all referenced Story Quest image/audio paths, missing files, unused files, extension mismatch candidates, and the currently tracked Story Quest replacement-quality issue.

Archived Kimi request docs live in `docs/assets/archive/kimi_requests/`. They were moved there because their active items are represented in the master queue, or because the docs reported no current missing rows.

Do not delete archived request docs without manual review. They may still be useful as historical prompts, character bibles, or import notes.

Large active detail docs remain beside the master queue when they contain full page text or generated row tables that should not be duplicated:
