# Kimi Long Vowels Media Request

Generate the replacement media pack for LiteracyPath Long Vowels and Silent E assessment questions.

## Output Folders

- Images: `public/images/assessment/long-vowels/{word}.webp`
- Audio: `public/audio/assessment/long-vowels/{word}.mp3`

## Image Rules

- 4:3 landscape WebP.
- Bright, child-safe K-2 literacy assessment style.
- Show the target object/action clearly.
- No printed words, letters, captions, signs, labels, speech bubbles, UI, or readable text.
- Simple background, warm natural colors, clear focus.

## Audio Rules

- MP3.
- Clear adult voice.
- Say only the target word.
- No article, sentence, sound effects, music, or extra silence.
