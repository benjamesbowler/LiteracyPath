# Media & asset archive — index

101 files, 745,441 words. This is the single largest thing in the repo.

**What this folder is.** Production paperwork for media: briefs sent to the media
generator, inventories of what came back, and coverage audits checking that every
question, book page and letter sound has the audio and artwork it needs.

**How to read it.** These are receipts, not reference. A request file describes work
that was commissioned once and is now done; an import audit records what actually
landed. Nothing here tells you how the app should behave — for that see
[the docs index](../INDEX.md). Come here when you need to answer "was this asset
ever made, and what was it asked to be?"
