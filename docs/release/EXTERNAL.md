# External validation register

Automated checks never fabricate a human observation. Human checking is active
and pass-by-exception: unreported behaviour is accepted, while a reported defect
is quarantined until its correction is retested.

These programmes do not block deployment to the current beta. Current media and
routes are accepted, and any observed bad pairing or route can be quarantined immediately.

| Item | Required external work | Status | Current truth |
| --- | --- | --- | --- |
