# Maths curriculum, assessment and reporting specification

## 1. Instructional model

Every concept moves through a connected representation sequence:

1. **Concrete:** move or organise countable objects.
2. **Pictorial:** interpret a frame, diagram, dot pattern, number line or drawing.
3. **Abstract:** connect the representation to numerals, equations and language.
4. **Transfer:** solve the same structure in a new context.

These are evidence dimensions, not learner labels. A learner may reason abstractly
in one skill and need concrete support in another.

Every lesson follows:

```text
Retrieve → Notice → Model → Make → Explain → Apply → Check
```

- **Retrieve:** short prerequisite prompt.
- **Notice:** teacher directs attention to the mathematical structure.
- **Model:** teacher demonstrates with one stable representation.
- **Make:** learner constructs or changes the representation.
- **Explain:** learner selects, points, arranges or discusses why it works.
- **Apply:** same structure in a changed surface context.
- **Check:** one independent exit item; `not checked` is valid.

## 3. Teaching cycles

Each year uses six cycles. A class may move non-linearly; prerequisites, not cycle
numbers, determine recommendations.

| Cycle | Foundation | Year 1 | Year 2 |
|---|---|---|---|
| 1 | quantities to 5 | number to 20 and facts to 10 | place value to 1,000 |
| 2 | quantities to 10 | addition/subtraction to 20 | facts to 20 and add/sub strategies |
| 3 | quantities to 20 and comparison | tens/ones and number to 120 | groups, arrays and twos facts |
| 4 | parts, wholes, adding/taking | skip count, sharing/grouping | fractions and money |
| 5 | pattern, shape and position | measure, shape and position | measure, time and maps |
| 6 | time, measure and data | money, data and chance | patterns, data and chance |

## 4. Assessment blueprints

Formal Maths checks are teacher-started and untimed. Each prompt displays one
construct, one requested action and the least extraneous visual detail possible.

### A. `count_collection`

- Prompt: “How many are there?”
- Response: choose numeral or construct matching quantity.
- Parameters: quantity, arrangement, object family, response mode.
- Evidence: counted quantity and chosen numeral.
- Distractors: `n-1`, `n+1`, last spatial row length; never random distant values.
- Misconceptions: `one_to_one`, `cardinality`, `spatial_extent_bias`.

### B. `quick_quantity`

- Prompt: “How many? Look, then choose.”
- Display: canonical or structured quantity to 5 for 1.5 seconds, then hide.
- No elapsed-time score.
- Evidence: quantity recognition across dice, finger and frame arrangements.
- Misconception: `counts_all`, `canonical_pattern_only`.

### C. `make_quantity`

- Prompt: “Make 7.”
- Response: tap-to-add counters to a frame; drag is optional.
- Evidence: final count, additions/removals, representation.
- Misconceptions: `one_to_one`, `stops_before_cardinality`, `frame_overfill`.

### D. `compare_quantities`

- Prompt: “Which has more?” / “Make them equal.”
- Vary spacing while keeping count deterministic.
- Evidence: choice or transformation.
- Misconceptions: `spatial_extent_bias`, `more_means_bigger_objects`.

### E. `part_whole`

- Prompt: “There are 8 altogether. Five are here. How many are hidden?”
- Response: construct missing part, then optionally select equation.
- Misconceptions: `whole_part_confusion`, `recounts_given_part`, `operation_symbol`.

### F. `number_line_move`

- Prompt: “Start at 8. Move forward 5. Where do you land?”
- Response: tap jumps or endpoint; no precision drag.
- Misconceptions: `counts_start_as_one`, `direction_confusion`, `unit_skip`.

### G. `group_and_share`

- Prompt: “Share 12 equally between 3 plates.” or “Make groups of 2.”
- Response: deal counters or select completed model.
- Misconceptions: `unequal_dealing`, `groups_vs_group_size`, `remainder_ignored`.

### H. `representation_match`

- Prompt: “Which shows 34?” / “Which equation matches the story?”
- Response: choose among meaningfully different representations.
- Misconceptions: `digit_as_quantity`, `tens_ones_reversed`, `surface_match`.

### I. `measure_compare`

- Prompt: “Which is longer?” / “Measure with these tiles.”
- Response: align units or select comparison.
- Misconceptions: `misaligned_origin`, `gaps_overlaps`, `unit_count_marks`.

### J. `shape_attribute`

- Prompt: “Choose every shape with four straight sides.”
- Response: multi-select across rotated/non-prototypical shapes.
- Misconceptions: `prototype_only`, `orientation_defines_shape`, `size_defines_shape`.

## 6. Misconception model

Never diagnose from one answer. One response creates a `possible signal`; repeated
aligned evidence across at least two items creates a teacher-facing `pattern to
check`. The app does not label a child with dyscalculia or any disability.

| Code | Observable pattern | Teacher check | Recommended response |
|---|---|---|---|
| unstable_order | sequence words change between attempts | count a fixed row together | rhythmic stable sequence with objects |
| one_to_one | skips or double-counts objects | ask learner to move each counted object | move-and-count tray |
| cardinality | recounts when asked “how many?” | ask after collection is covered | emphasise final number names the whole set |
| spatial_extent_bias | chooses longer-spread set as more | align one-to-one | matched rows then vary spacing |
| canonical_pattern_only | recognises dice five but not scattered five | show varied arrangements | compose five in multiple ways |
| whole_part_confusion | treats known part as whole | build whole with two colours | cover/uncover part-whole model |
| counts_start_as_one | includes starting number as first jump | mark start and each landing | physical/tap number-line jumps |
| direction_confusion | adds by moving left or subtracts right | narrate change action | connect story action to line direction |
| tens_ones_reversed | models 34 as 3 ones and 4 tens | bundle loose units | say “3 tens and 4 ones” before numeral |
| zero_placeholder | reads 205 as 25 or models no tens incorrectly | empty place-value column | contrast 205, 250 and 25 |
| groups_vs_group_size | swaps 3 groups of 4 with 4 groups of 3 without noticing context | label groups and items | build both and discuss equivalence/context |
| unequal_partition | fractional parts have unequal size | fold/overlay comparison | equal-parts language and construction |
| gaps_overlaps | measurement units leave gaps/overlap | align repeated units | tile a length before counting |
| prototype_only | rejects rotated or narrow valid shape | sort varied examples/nonexamples | discuss defining attributes |
| graph_scale | counts height rather than represented units | annotate scale/unit | rebuild graph from objects |

## 7. Assessment sessions

- Diagnostic entry check: 6–10 items chosen from prerequisites and target.
- Skill check: 8–12 items spanning at least two representations.
- Exit observation: one teacher-recorded item, stored as observation evidence.
- Retention check: 4–6 items after an appropriate interval, initially teacher
  scheduled; no automatic high-stakes demotion until calibrated.
- Stop rule: after visible distress, three consecutive non-responses, or teacher
  action. Unadministered items remain `not_checked`.
- Audio replay, counter reset and accessibility support are logged but never
  treated as cheating.

## 8. Reporting hierarchy

```text
Subject: Maths
├── Year level
├── Strand
│   ├── Number
│   ├── Algebra
│   ├── Measurement
│   ├── Space
│   ├── Statistics
│   └── Probability
├── Skill
├── Representation
└── Item evidence
```

### Teacher class report

- class strand overview with statuses, not a league table;
- skill-by-learner heatmap with neutral `not checked` cells;
- representation coverage: concrete, pictorial, abstract, transfer;
- suggested small groups based on the same next teaching action;
- misconception patterns labelled “Check whether…”;
- freshness and evidence count visible beside every claim;
- filter by year, cycle, strand, skill and evidence source.

### Learner report

- current strengths with named evidence;
- developing skills;
- representation(s) successfully used;
- patterns to check;
- next teacher action and next family activity;
- history that distinguishes first acquisition and later retention.

### Family report

Use plain language:

```text
Developing: Sam can make and recognise groups to 8 using counters and a ten
frame. Next, practise noticing 5 and some more without counting every object.
```

Do not display raw misconception codes, percentile rankings, diagnostic labels or
an overall “maths age”.

## 9. Recommendation logic

```js
export function recommendMathsNextAction(snapshot, skill) {
  if (snapshot.status === "not_checked") return `check:${skill.id}`;
  if (snapshot.misconceptionCodes.includes("one_to_one")) return "lesson:move-and-count";
  if (!snapshot.representationsSeen.includes("pictorial")) return `bridge:${skill.id}:pictorial`;
  if (!snapshot.representationsSeen.includes("abstract")) return `bridge:${skill.id}:abstract`;
  if (snapshot.status === "secure" && !snapshot.retainedAt) return `retain:${skill.id}`;
  return `teach:${skill.id}`;
}
```

Recommendations are deterministic, versioned and explainable. AI may help draft a
teacher-facing explanation, but it may not determine mastery or select an unlogged
intervention.

## 10. Content and assessment gates

Every skill must pass:

1. standards crosswalk exists;
2. prerequisites form an acyclic graph;
3. two or more representations are available;
4. assessment item has exactly one valid interpretation;
5. visual quantity audit matches the data model;
6. distractors represent named plausible misconceptions;
7. media exists and exact prompt audio is mapped;
8. keyboard/tap alternatives work;
9. wrong answers receive specific supported retry language;
10. evidence claim matches the activity source;
11. browser test covers mobile portrait and classroom desktop;
12. a teacher can identify the next action from the report.
