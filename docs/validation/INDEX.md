# Validation run archive — index

98 files, 221,575 words.

**What this folder is.** Point-in-time audit reports. Each one was generated to answer
a single question — does every skill have media, do answer options render, is the
question bank internally consistent — and then the code moved on.

**How to read it.** Treat every file here as dated evidence, not as a current
statement about the app. If you want to know whether something is true *now*, run the
matching gate in `tools/` rather than trusting a report in here. These are kept because
they show what was checked and what was found at the time.
