## Practical Read

- Best immediate phonics use: Final Sounds, Rhyming, Initial Sounds, Blends, Vowel Teams, CVC/Short Vowels, Long Vowels, R-Controlled Vowels.
- Best grammar/vocab use: Antonyms/Synonyms, Plurals, Prefix/Suffix, Nouns, Verbs, Adjectives, Prepositions.
- Best reading/comprehension use: sentence cloze, context clues, guided reading vocabulary, and image-supported comprehension prompts.
- Homophones/Homonyms did not get a useful count from this metadata alone; that needs pair/relation metadata, not just word/media metadata.

## Notes

- Eligibility here is metadata-based. A word still needs template-specific QA before becoming a live question.
- Low-imageability function words are better for HFW, sentence cloze, guided reading, and context-clue work than image-only answer cards.
- Concrete high/medium imageability words are best for picture-backed phonics, grammar, vocabulary, and comprehension answer cards.
- The first-10 skill top-up already uses today media for Blends; HFW depth was topped up via generated image-context/letter-build questions.
