# Bounded agent workflow

The original decision required research, implementation and verification lanes
for substantial work. Its purpose was scoped ownership, selective context and
evidence-based handoff without adding a hosted memory service.

The [selective guidance decision](2026-09-12-selective-agent-guidance.md) replaces
the mandatory lane structure. Delegation is optional and the parent still owns
scope and release. Use the current [task brief](../AGENT_TASK_BRIEF.md) and
[agent workflow](../../engineering/AGENT_WORKFLOW.md); this note preserves
rationale only, not active instructions.
