# Kimi Audio Request — Short words said as ONE word (EL Skills Quest)

Several very short words in the Skills Quest are being said letter-by-letter
(e.g. "am" comes out as "a… m", "ax" as "a… x"). In the Word Build station this
makes children think the answer is one letter, so they can't complete the round.
Re-record the words below in the **gold voice** as **one natural, blended word**.

**Attach these reference clips so the voice matches exactly:**
- `public/audio/child-mode/clean-human/words/splash.mp3`

- any Dino Pals `page-001.mp3`

**Non-negotiable rules:**

> - Same warm female gold narrator as the reference clips.
> - **Say each as ONE blended word — never spell the letters out, never pause
>   between sounds.** "am" rhymes with "ham"; "ax" rhymes with "tax".
> - Flat short A (the /æ/ in "cat") — never a long "ah" or "ay".
> - One clear, unhurried take per file. Natural and warm, never robotic.
> - Overwrite the same filenames; the app picks them up automatically.
