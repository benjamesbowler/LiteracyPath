# Animation production

Read the [animation production bible](../../../docs/design/ANIMATION_PRODUCTION_BIBLE.md)
and the exact story/canon sources linked from [the index](../../../docs/INDEX.md).
If authoring belongs to another animation repository, locate it and read its
current instructions and production contracts before editing there. A local
folder name or old tool list cannot establish the active studio.

Identify the finished deliverable: film, rig, scene, or explicitly requested
test. Preserve its complete scope. Plan against final narration, shot purpose,
character models, staging, contacts and exposure. Choose an eligible authoring
tool from current project sources and the user's direction; tool choice does
not lower the rendered quality requirements.

Check connected anatomy, limb count, source-art likeness, scale, depth, prop
contact, weight, anticipation, arcs and recovery together. Camera movement or
translation of a still does not establish character animation. For a usable
rig, verify semantic parts, true alpha where needed, shared registration and
actual import/deformation in the requested tool.

Review the exported movie with sound at normal speed and inspect contact and
pose changes frame by frame. Compare every scene with its exact text and
world-qualified canon. Confirm duration, frame rate, audio, editable sources
and delivery formats against the governing bible and task brief.

[Task gates](../../../docs/verification/TASK_GATES.md) distinguish these direct
checks from automated media integrity. A contact sheet, manifest, property
check or technically valid render is intermediate evidence. Correct observed
defects before calling the requested artifact finished; preserve production
inputs and required review evidence.
